A full stack web application engineered to showcase technical proficiencies across software development and cloud architecture. Designed with a rigorous focus on Data Gathering, Discernment, and Decision making, this portfolio bridges the gap between hardware prototyping and scalable web services. The architecture reflects best practices suited for enterprise environments including telecommunications and network security sectors.

System Architecture
The project utilizes a decoupled client and server model. The backend operates on an Express server managing modular REST endpoints while the frontend leverages a highly responsive React environment to consume and display data seamlessly.

Core Features
Live API Inspector: A dedicated interface allowing users to test active server endpoints and view real time JSON responses.

Modular REST Endpoints: Isolated routes handling profile statistics, technical skills, and project data.

Secure Contact System: A custom inquiry router with input validation and unique ticket ID generation.

Dynamic Interface: Built with Tailwind CSS and Framer Motion for smooth viewport transitions and scroll depth tracking.

Technology Stack
- Frontend: React 19, TypeScript, Vite, Tailwind CSS.

- Backend: Node.js, Express.

- Integrations: Google Gemini AI.
